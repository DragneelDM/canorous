# Deployment Guide

This project combines a Next.js static export with PHP files. Here's how to deploy everything together.

## Project Structure

```
canorous/
├── out/                    # Next.js static export (generated by `npm run build`)
├── verify.php              # Root-level PHP file
├── portal/                 # PHP portal directory
│   ├── index.php
│   ├── employees.php
│   ├── create.php
│   ├── edit.php
│   ├── regen.php
│   ├── delete.php
│   ├── config.php
│   ├── _header.php
│   └── _footer.php
├── htaccess                # Apache .htaccess (rename to .htaccess on server)
└── ...
```

## Deployment Steps

### 1. Build Next.js Static Export

```bash
npm run build
```

This generates all static files in the `out/` directory.

### 2. Deploy to public_html

When deploying to your web server (e.g., cPanel), you need to:

1. **Copy Next.js static files** from `out/` to `public_html/`
2. **Copy PHP files** to `public_html/`
3. **Copy portal directory** to `public_html/portal/`
4. **Copy and rename htaccess** to `public_html/.htaccess`

### Manual Deployment

```bash
# On your local machine (after building)
cd out
# Copy all contents to public_html via FTP/SFTP/cPanel File Manager

# Copy PHP files
cp ../verify.php /path/to/public_html/
cp -r ../portal /path/to/public_html/
cp ../htaccess /path/to/public_html/.htaccess
```

### Automated Deployment Script

You can create a deployment script. Here's an example for Windows PowerShell:

```powershell
# deploy.ps1
$publicHtml = "C:\path\to\public_html"

# Build Next.js
Write-Host "Building Next.js..." -ForegroundColor Green
npm run build

# Copy Next.js output
Write-Host "Copying Next.js files..." -ForegroundColor Green
Copy-Item -Path "out\*" -Destination $publicHtml -Recurse -Force

# Copy PHP files
Write-Host "Copying PHP files..." -ForegroundColor Green
Copy-Item -Path "verify.php" -Destination $publicHtml -Force
Copy-Item -Path "portal" -Destination "$publicHtml\portal" -Recurse -Force

# Copy .htaccess
Write-Host "Copying .htaccess..." -ForegroundColor Green
Copy-Item -Path "htaccess" -Destination "$publicHtml\.htaccess" -Force

Write-Host "Deployment complete!" -ForegroundColor Green
```

## How It Works

1. **PHP Files**: Served directly by Apache (verify.php, portal/*.php)
2. **Next.js Static Files**: Served as static HTML/CSS/JS
3. **Routing**: `.htaccess` handles:
   - Direct file serving (PHP, static assets)
   - `/verify/TOKEN` → `verify.php?t=TOKEN`
   - `/portal/*` → PHP files
   - All other routes → Next.js `index.html` (for client-side routing)

## Important Notes

- Make sure your server has PHP enabled
- Update database credentials in `portal/config.php` and `verify.php` if needed
- The `.htaccess` file must be named exactly `.htaccess` (with the leading dot) on the server
- Ensure `mod_rewrite` is enabled on your Apache server
- Next.js routes work via client-side routing, so all routes should work correctly

## Testing Locally

For local testing with PHP, you can use PHP's built-in server:

```bash
# Terminal 1: Build Next.js
npm run build

# Terminal 2: Serve PHP files (from project root)
php -S localhost:8000

# Or use a tool like XAMPP/WAMP/MAMP
```

Note: For full Next.js + PHP testing, you'll need a proper web server like Apache or Nginx.
